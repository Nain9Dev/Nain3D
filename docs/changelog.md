# Changelog

## Unreleased — Visual redesign and recording mode

Specification: `specs/002-visual-redesign/`. Decisions: ADR-002 to ADR-006 (`Approved`). Presentation
and sample models only: business rules, API contracts and schemas are unchanged.

### Added

- Hero sample models generated by code (`npm run generate:samples`): brass industrial valve, monitor with a
  lit screen, chair and a giant chair. PBR materials, studio lighting, soft shadows, eased rotation.
- Scale overlay for non-conformant assets: red real-size box, white limit box and ruler, drawn from the API payload.
- Animated verdict reveal (checks ticked one by one, badge, latency counter) and a one-gesture
  conformant / non-conformant switch (button and `C`).
- Recording mode `?mode=record` for 1080x1920 and 1920x1080 with a deterministic timeline and a 20 s sequence;
  `docs/demo-recording-script.md`.
- Spanish (source) and English interface with a typed catalogue, language switch, `?lang=` and `localStorage`
  persistence; parity test for missing and extra keys.
- NainDev brand tokens and self-hosted Urbanist and IBM Plex Mono fonts.
- Vitest, ESLint (with accessibility rules) and Playwright suites; reproducible captures in
  `docs/assets/visual-redesign/`; measurements in `docs/visual-redesign-metrics.md`.
- `tests/test_hero_samples.py`: each generated GLB keeps its documented verdict in the Python engine.

- Photoreal hero pair `sample-shoe` / `sample-oversized-shoe` (Materials Variants Shoe, Shopify, CC BY 4.0):
  one-line credit in the 3D frame, `npm run optimize:models` pipeline (7.8 MB to 0.83 MB, source hash checked),
  data-driven sample catalogue `src/samples/catalog.ts`. ADR-007 (`Proposed`).

### Changed

- Client renderer: `<model-viewer>` replaced by a lazily loaded three.js stage (ADR-002).
- `GET /api/v1/conformance/samples/{id}/download` serves the generated hero GLBs when present.
- Cold LCP 1,120 ms to 140 ms and third-party hosts 6 to 1; transferred bytes 424 kB to 452 kB (see metrics).

### Fixed

- `npm run build` failed on `master` (`api.ts` read a `passed` field that `EvaluationResult` does not have).

## 1.0.0 — 2026-10-14 — Nain3D Architecture Modernization

Governing decision: ADR-001 (`Approved`). Specification: `specs/001-modernization-and-showcase/`.

### Added

- **FastAPI Modular Backend** (`src/nain3d/`) on port `8104`:
  - `POST /api/v1/conformance/evaluate`: Multipart `.glb` model evaluation with geometric feature extraction, AI proposal, and fail-closed deterministic contract enforcement.
  - `GET /api/v1/conformance/profiles`: Contract profile registry (`Monitor`, `Mobiliario (Chair)`, `Pieza Industrial`, `Prop / Decorativo`).
  - `GET /api/v1/conformance/samples` & `/download`: Built-in synthetic 3D GLB generator for zero-external-dependency benchmarking.
  - `GET /health` & `GET /health/ready`: Liveness and readiness probes.
  - Interactive Scalar OpenAPI Reference mounted at `/docs`.
- **Reactive Vue 3 + TypeScript Client** (`Nain3D.Client/`) on port `5376`:
  - Interactive Google `<model-viewer>` viewport with 360-degree rotation, lighting, and drag-and-drop `.glb` upload.
  - Side-by-side presentation: *"La IA Propone"* (probabilistic classification) vs *"El Contrato Dispone"* (deterministic mathematical gate).
  - Built-in Synthetic Samples drawer for instant 1-click model testing.
  - Dark glassmorphic design system matching the `naindev.com` portfolio standard.
- Comprehensive `pytest` test suite covering domain schemas, contract evaluator fail-closed logic, and API endpoints (9/9 passed).
- Governance documents: `AGENTS.md`, `CLAUDE.md`, `SECURITY.md`, `.editorconfig`.

### Changed

- Unfroze repository from legacy archived status and established open-source reference branding as **Nain3D Gateway**.
- Replaced monolithic Streamlit script with decoupled REST API + Vue 3 architecture.
